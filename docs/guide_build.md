ガスケットマウントケース
画像
上面に来る『アッパーケース』と底面に来る『ボトムケース』の２つで構成されます。家庭用3Dプリンターで出力したもので、PLAという一般的な素材を使用しています。

フォームシール
基板（トッププレート）を挟み込みケースに固定するために使用します。ポロンシートを手作業で切り出して両面テープを貼り付けたものです。

M2ネジ(長さ6mm)
アッパーケースを左右からネジ止めする際に使用します。長さ6〜10mmのネジを使用できますが、長さ6mmが適切です。

M2ナット
ボトムケースに嵌め込み、アッパーケースをネジ止めする際に使用します。一般的な外径4mm、厚さ1.6mmのものです。ケースもこちらに合わせて設計しています。

ゴム足(直径7mm×厚さ1.5mm)
ボトムケースに滑り止めとして使用します。経年劣化で剥がれた場合、Amazon等で同じものを購入することができます。

ケースキットの組み立て
40Plus-LPを分解する
ケースのネジ止めを外して、基板とケースフォームを取り外してください。キーキャップ等の取り外しは不要です。

ボトムケースの両端にナットを嵌め込む
画像
奥まで嵌め込むと左側のナットの状態になる。
ボトムケースの両端にスリットがありますので、ナットを嵌め込んでください。ナットの頂点が真上に来るように軽い力で奥まで嵌め込んでください。正しく嵌まれば左右から見た時に向こう側が見えます。

ケースの両端にフォームシールを貼り付ける
画像
ボトムケース　ナットのスリットを覆う
画像
アッパーケース　壁面に沿わせる
アッパーケースとボトムケースの両端にフォームシールを貼り付けてください。ボトムケースはナットのスリットを覆うかたちになります。

ケースフォームを敷く
画像
切り欠きを合わせる
ボトムケースとケースフォームの切り欠きを合わせて敷いてください。

ボトムケースに基板を設置する
基板をボトムケースに合わせて設置してください。
この時点で固定はありませんので置くだけになります。

アッパーケースをネジ止めする
画像
アッパーケースを押さえてネジ穴を合わせる
アッパーケースとボトムケースの切り欠きを合わせて被せます。アッパーケースを上から押して、ボトムケースのネジ穴を合わせてネジ止めしてください。ネジ穴はタイトに設計していますので、締め回すと上手く入りやすいです。

ケースが割れる可能性がありますので、ネジは締めすぎないようにしてください。ネジが入らない場合は、アッパーケースを押す力を調整して、ボトムケースのネジ穴を合わせてください。ネジを締め込んでも空回りする場合は、ナットが適切な位置にあるか確認してください。

ゴム足を貼り付ける
ボトムケースの四隅にゴム足を貼り付けます。

補足　マグネット端子
画像
マグネット端子がツライチになる
USBコネクタ保護のため、マグネット端子をおすすめします。また、マグネット端子を取り付けた方がケースの切り欠きが目立ちません。L字型、I字型ともに取り付け可能です。
